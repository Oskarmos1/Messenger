# Messenger

A simple Spring Boot REST application that manages and serves chat messages using Spring Data JPA and an in-memory H2 database.

---

## 🚀 Features

- **REST API Endpoint**: Fetch all stored messages via `/api/messages`.
- **In-Memory Database**: Uses H2 database for lightweight and fast execution.
- **Sample Data Initialization**: Automatically populates sample messages on startup using `DataInitializer`.
- **H2 Web Console**: Access and inspect the database directly via a web browser.

---

## 🛠️ Tech Stack

- **Java**: 25
- **Framework**: Spring Boot 4.1.0
- **Database**: H2 (In-memory)
- **Persistence**: Spring Data JPA / Hibernate
- **Build Tool**: Gradle (Kotlin DSL)

---

## 📋 Prerequisites

- **Java Development Kit (JDK)** 25 or higher installed and configured.
